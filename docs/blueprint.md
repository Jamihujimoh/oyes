# **App Name**: IdeaSpark

## Core Features:

- Idea Creation: Users can quickly add new ideas and thoughts as plain text notes.
- Idea List & Overview: Display a browsable list of all saved ideas, showing a title or first few lines of each.
- Idea Detail View: Allow users to view the full content of a selected idea in a dedicated screen.
- Edit & Delete Ideas: Functionality to update existing idea content or remove ideas completely.
- AI Idea Expander Tool: A tool that takes a short idea prompt from the user and expands upon it or suggests related concepts to foster further ideation.
- Basic Search & Filter: Enable users to search for ideas by keywords or filter them by basic criteria.
- Persistent Idea Storage: Securely store and retrieve user-generated ideas.

## Style Guidelines:

- The app uses a light color scheme to convey clarity and freshness. Primary color is a sophisticated blue (#3989CC), representing stability and inspiration. It stands out clearly against the lighter background.
- The background color is a very light, desaturated blue (#E8F1F7), visually related to the primary color but serving as a neutral canvas for content.
- An accent color of refreshing cyan-green (#107E99) is used for interactive elements and highlights, providing an analogous but distinct contrast to the primary blue.
- Body and headline font: 'Inter' (sans-serif) for its modern, legible, and objective feel, ensuring clear readability across all content.
- Use a consistent set of minimalist, outline-style icons to maintain a clean and uncluttered interface. Icons should be easily understandable for core actions like 'add', 'edit', 'delete', and 'search'.
- A clean and spacious layout emphasizing content, with clear hierarchy. Responsive design ensures usability across various screen sizes, prioritizing readability and ease of navigation.
- Subtle, fluid transitions and micro-animations for feedback on user interactions, enhancing the sense of responsiveness without distracting from the content. Examples include smooth fades on content changes or slight scale effects on button presses.
